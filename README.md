# ModelHarbor

A self-hosted, mobile-friendly AI model inventory and management platform for ComfyUI, Ollama, Hugging Face, and Civitai.

## Roadmap

1. Read-only model inventory for Windows ComfyUI directories and Ollama.
2. NAS-hosted API and mobile dashboard.
3. Source-aware update detection and compatibility review.
4. Verified, approval-based downloads with rollback.

ModelHarbor never modifies installed model files during inventory scans.

## Development

The first milestone will be developed on the `feat/phase1-foundation` branch and reviewed through a pull request.
